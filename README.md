# Harbor Registry Lab Assessment
# Project Overview

This project demonstrates the installation, configuration, and usage of Harbor Container Registry on Ubuntu using Docker Compose.

The lab covers:

Installing Harbor using Docker Compose
Configuring Harbor with HTTPS
Creating Harbor projects and users
Pushing and pulling Docker images
Verifying image repositories and user access

# HashiCorp Vault Lab Assessment

## Overview

This project documents the implementation of the **KIAQ Technology HashiCorp Vault Lab Assessment**.

The lab covers:

1. Install and Initialize Vault
2. Unseal Vault and Configure Authentication
3. Enable the KV Secrets Engine
4. Store and Retrieve Secrets
5. Create Policies and Verify Access

Vault is configured to run locally using **HTTPS on port 8200**.
